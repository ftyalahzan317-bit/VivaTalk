# VivaTalk MVP

نسخة أولية لتطبيق يجمع:
- لايفات فيديو
- غرف دردشة صوتية
- تعليقات
- إعجابات
- هدايا
- ملفات شخصية

## التشغيل
1. ثبّت Flutter.
2. افتح المشروع في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
4. شغّل:
   flutter run

## المرحلة التالية
هذه النسخة هي واجهة MVP وليست خدمة بث حقيقية بعد.
لتحويلها إلى تطبيق إنتاجي نضيف:
- Backend وحسابات المستخدمين
- بث فيديو وصوت حقيقي عبر WebRTC/مزود RTC
- قاعدة بيانات
- إشعارات Push
- نظام العملات والهدايا
- إدارة ومراقبة المحتوى
- تسجيل الدخول
